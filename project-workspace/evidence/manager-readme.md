# Manager-Facing README (Draft) — For the Pho65 Owner

> Written for the owner, in plain language. The same text is the "For the owner" section of `project-workspace/README.md`.

## What it does

- Each week, it tells you which regular customers haven't been in for three weeks or more, and writes a short "we miss you" note you can read, change, and send yourself.
- It warns you when too many catering orders land in the same two-hour window, and names a quieter time that same day to offer instead.
- It sums up the week in one short paragraph at the top of the page, so you don't have to read any tables.

## What it does not do

It never sends a message by itself; there is no send button anywhere in the app. It doesn't run a membership or points program. It never scores or follows up with anyone who hasn't agreed to be contacted, or anyone who left no phone number.

## One known limitation

It recognises a returning customer only by phone number. If a number is typed wrong once, the same person looks like two people and can be missed. That is exactly what happened to one regular in our test data. If a family shares one phone, they look like one person.

## One next step

Ask staff to read the phone number back to the customer at checkout, and to ask about contact consent every time. When the page shows a "Check these names" warning, have someone look at it that week.
